# Requirements

- MATLAB R2025a recommended.
- Windows, Linux or macOS supported by MATLAB.
- No physical sensors or quantum hardware required.
- No specialized toolbox is required by the core numerical functions.
- Plotting scripts use modern base-MATLAB graphics functions including `tiledlayout`, `heatmap`, `boxchart` and `exportgraphics`.

The project has not been regression-tested in older MATLAB releases.
